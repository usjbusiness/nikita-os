NIKITA OS 5.2 — ОБНОВЛЕНИЕ ДЛЯ GITHUB

УСТАНОВКА
1. Распакуй архив на компьютере.
2. GitHub → usjbusiness/nikita-os → ветка main → Add file → Upload files.
3. Перетащи ВСЁ содержимое архива в корень репозитория: папки public, scripts,
   tests и файлы рядом с ними. Сохрани вложенные пути, особенно public/vendor.
   Сам ZIP и внешнюю папку с названием ZIP загружать не нужно.
4. Commit changes одним коммитом. Частичная загрузка приведёт к ошибке проверки сборки.
5. Дождись успешной публикации Vercel. Номер версии на сайте должен быть 5.2.0.
6. Настройки сайта → Перезагрузить интерфейс. Если старая установленная PWA
   осталась открытой, закрой и открой её после обновления.

Не удаляй репозиторий. Не меняй переменные окружения, не выполняй заново SQL,
не заменяй state или seed в Supabase. Это накопительное обновление 5.0/5.1 → 5.2.
Предыдущие функции «Мои классы» входят в пакет. Личный academic JSON не включён.

ЧТО ИЗМЕНИЛОСЬ
- Отступы safe area iPhone, непрозрачная статусная область PWA, закреплённая верхняя
  панель, перенос длинных заголовков и исправление узких панелей домашнего.
- На телефоне учебные блоки занимают всю ширину; увеличены читаемость и кнопки.
- На главной и в домашних заданиях появилась панель из трёх инструментов.
- Новые заметки хранятся в существующем защищённом state; отдельная вкладка «Заметки».
- Новые поля состояния обратно совместимы со старыми данными. Новых таблиц SQL нет.

КАРТИНКА РАСПИСАНИЯ
Выбери нужный день в расписании → День в PNG → Скачать PNG либо Поделиться.
На iPhone в меню общего доступа можно сохранить изображение. Запасной способ:
удерживать изображение предпросмотра. На картинке весь выбранный день,
время New York, название события и место. Создаётся локально без загрузки на сервер.

ГОЛОСОВЫЕ ЗАМЕТКИ
Заметка / голос → название и текст → язык → Начать диктовку → разрешить микрофон.
После диктовки проверь текст и нажми Сохранить заметку. Заметка появится во вкладке
«Заметки». В «Личном фокусе» также есть диктовка для быстрой заметки.
Поддержка Web Speech API зависит от браузера/ОС. Если API недоступен, нажми
поле текста и используй микрофон клавиатуры iPhone. Распознавание может использовать
сервис производителя браузера. Nikita OS не записывает и не хранит аудиофайлы.
Для микрофона нужен HTTPS и разрешение пользователя. Проверена программная
обработка голосового API; реальный микрофон iPhone здесь не тестировался.

СИЛЛАБУСЫ И ДОМАШНЕЕ
1. Силлабус / расписание → Куда добавить: Домашнее.
2. Укажи предмет и год для дат без года.
3. Выбери PDF, DOCX, TXT или CSV, либо вставь текст.
4. Разобрать и проверить → исправь строки и даты, отметь только настоящие задания.
5. Добавить отмеченные строки → подтвердить. Они появятся в «Домашнее и дела».

Разбор локальный, без внешнего AI. Это извлечение строк с датами, а не полноценное
смысловое понимание документа. Учебные политики и другие датированные строки
тоже могут попасть в предпросмотр: сними лишние галочки. Строки без даты и строки
с несколькими неоднозначными датами не выбираются автоматически. Номера глав
не считаются дедлайнами. Всегда сверяй полученные задания с документом.
Даты вида 10/22 — месяц/день; 22.10 — день.месяц. Время сдачи сохраняется
в исходном описании, а поле срока задачи поддерживает календарную дату.
Сканы PDF и фотографии без текстового слоя требуют OCR, которого здесь нет.
Формат .doc не поддерживается: сохрани как .docx или PDF.
Лимиты: файл до 12 МБ, PDF до 150 страниц, текст до 250000 символов,
один предпросмотр до 1000 строк. Файлы не попадают в публичный репозиторий.
Повторные строки с той же датой, предметом и названием пропускаются.

РАСПИСАНИЕ В КАЛЕНДАРЬ
Выбери Календарь в поле «Куда добавить». Доступны CSV, ICS и датированный текст.
ICS выбирает календарь автоматически; можно изменить назначение.
Для CSV используй заголовки title,date,course,start,end,location,notes.
Пример строки: Seminar,2026-10-22,COMP 210,14:00,14:50,Room 100,
Можно использовать соответствующие русские заголовки.
Простые ежедневные/еженедельные ICS-повторы с COUNT/UNTIL разворачиваются.
Сложные правила и исключения помечаются предупреждением, а не считаются полными.
Для часовых поясов, отличных от New York/UTC, проверь и исправь время вручную.
Ночной/многодневный интервал нужно разделить на записи по дням.
Недельная сетка без календарных дат и даты вида «Week 3» требуют ручного уточнения:
даты начала/окончания семестра, каникулы и праздники не выдумываются.

ПРОВЕРКА
23 автоматических теста; npm run build; интерфейс на 320/390/1440 px;
отступ safe area смоделирован на 47 px. Проверены скачивание PNG, сохранение заметок,
текстовые PDF и DOCX под CSP, добавление домашних заданий и отсутствие дублей,
простые повторения ICS, перезагрузка и блокировка данных после выхода.
На реальном устройстве iOS проверка пока не выполнена.
