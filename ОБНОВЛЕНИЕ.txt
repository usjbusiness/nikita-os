NIKITA OS 3 — ОБНОВИТЬ РАБОТАЮЩИЙ САЙТ

1. На старом сайте: Настройки → Скачать JSON-копию. Сохрани у себя.
2. Распакуй ZIP. Открой внутри папку nikita-os.
3. Открой свой приватный репозиторий GitHub nikita-os. Оставайся в корне репозитория, не в папке lib или public.
4. Add file → Upload files → перетащи ВСЁ содержимое распакованной папки nikita-os (файлы и вложенные папки). Не перетаскивай ZIP или внешнюю папку nikita-os. Нажми Commit changes.
5. Vercel → Deployments: дождись Ready у нового deployment с этим commit. Если он не появился автоматически, запусти Redeploy последнего кода.
6. Открой https://nikita-os-azure.vercel.app и обнови страницу. Установленное приложение закрой полностью и открой снова.

SUPABASE И КЛЮЧИ НЕ ТРОГАЙ. Новый SQL не нужен. Данные в таблицах не удаляй. Резервную копию просто храни — восстанавливать её при обычном обновлении не нужно.

Обновить надо весь проект, в том числе новые migrations.mjs и validation.mjs, lib/handler.mjs, public/app.js, public/style.css, public/sw.js и иконки. Одной замены CSS недостаточно.

После первого входа версия 3 автоматически переносит исходную игру EHL All Stars с 21 на 20 октября 2026, не сбрасывая другие данные. Если ты уже перенёс её на иной день, обновление не переопределит дату.

Главная показывает полный выбранный день без ограничения восьми строк. Учебные задания и личные дела разделены. Новые события добавляются кнопкой «Добавить событие» над расписанием или «+ Событие» в верхней панели.

Проверь после обновления:
— Главная графитовая, быстрые кнопки сверху, расписание широкое.
— На пятницу видны все записи дня, не только утро.
— Во вторник 20 октября стоит игра EHL All Stars, в среду её нет.
— Создай тестовое событие и задачу, обнови страницу: записи должны сохраниться.
