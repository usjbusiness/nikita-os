# Проверка версии 2.0

## Архитектура
Vercel Functions + Supabase Postgres. SQLite и Railway удалены. Нет production-режима mock-хранилища. Проверены синтаксис JS, структура сборки и schema seed-файла.

## Автоматические тесты
`npm test`:
- авторизация, cookies, отклонение чужого Origin;
- версии данных и конфликт одновременной записи;
- сохранение избранных ссылок и логотипов событий;
- валидация URL, дат и недопустимого имени логотипа;
- выход, смена PIN и ограничение попыток;
- загрузка резервных копий версии 1;
- обязательные параметры конфигурации и HTTPS;
- Supabase REST adapter: server-only API key и атомарный save RPC.

Данные для unit/API-тестов обслуживает mock-адаптер. Это проверка логики, не подтверждение живого соединения с пользовательским Supabase.

## Проверка интерфейса

Локальный Chromium, desktop 1440 px / mobile 390 px: 18 сценариев завершены успешно, ошибок JavaScript нет. Проверены вход/выход, сохранение после перезагрузки, задачи и статусы, курсы и повторы, ссылки и избранное, резервное копирование, фокус и готовность, manifest и активный service worker. Все 8 мобильных разделов — без горизонтального переполнения страницы.

Визуально проверены главная с быстрыми кнопками и синими тренировками, пятница 23 октября с логотипами и фиолетовой встречей с Марком, мобильный каталог ссылок, меню быстрых переходов и редактор события с доступными кнопками сохранения. Интерфейс проверялся с тестовым адаптером; реальные Supabase и Vercel в этих тестах не использовались.

## Не выполнено автоматически
- Запуск setup.sql в реальном проекте Supabase пользователя.
- Живое развёртывание на Vercel.
- Установка на физические устройства пользователя.

Исходные логотипы взяты из предоставленного HTML-блока расписания. В архиве нет рабочего PIN, реального Supabase key, SESSION_SECRET или тестовой базы.
