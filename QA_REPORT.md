# Nikita OS 3 — проверка

## Автоматические проверки
- npm run build: схема seed и обязательные файлы Vercel проверены.
- npm test: 8 тестов проходят. Авторизация, Origin/cookies, PIN rotation, общий rate limit, ревизии, валидация, безопасные диагностические коды, Supabase REST adapter, совместимость копий и миграции.
- Проверен авторизованный GET на старом документе: игра меняет только 21 → 20 октября, пользовательская заметка сохраняется, ревизия повышается один раз. Повторное открытие не повторяет миграцию. Вручную изменённая дата не переопределяется.

## Chromium / desktop 1440 и mobile 390
- Главная показывает весь день: 12/12 записей понедельника; 17/17 пятницы до добавления тестового события.
- Видимая кнопка «Добавить событие»: запись на выбранную дату, важность, сохранение после перезагрузки.
- Игра EHL All Stars — вторник 20 октября, в среду отсутствует.
- Учебная задача: быстрое добавление, предмет, срок, группировка по дате, редактирование.
- Личные дела: отдельный список, быстрое добавление, одна галочка завершает; возврат из выполненных.
- Компактные ссылки, избранное и меню быстрых переходов.
- Планировщик курсов и добавление повторов в календарь сохранены.
- Фокус, готовность и JSON backup проверены.
- Все восемь разделов на desktop и mobile — без горизонтального переполнения страницы; ошибок JavaScript нет.
- PWA manifest и активный service worker проверены.

## Визуальная проверка
Отдельно отрендерены и просмотрены восемь разделов на desktop и mobile, новый вход, загрузка, раскрытое меню избранного и редактор события. Главная и календарь перепроверены после последних правок. Расписание читабельно на всю доступную ширину, цветовые категории и исходные логотипы сохранены. На телефоне формы прокручиваются внутри модального окна, кнопки сохранения доступны.

Проверены контрасты основных текстовых пар: 8.33:1 для вторичного текста, 10.48–12.1:1 на цветных строках, 12.63:1 на основной кнопке. Границы полей усилены после проверки.

## Границы проверки
Вся интеграционная проверка выполнена на изолированном тестовом адаптере хранилища. Новая версия не опубликована в Vercel пользователя; реальная Supabase-база не читалась и не изменялась. Существующее setup.sql не требуется запускать заново для обновления. Физическая установка на устройства пользователя не проверялась. Автосинхронизации с внешними источниками нет.

В архиве нет реальных ключей, рабочего PIN, тестовых пользовательских записей, .env.local или тестового сервера браузерной проверки.
