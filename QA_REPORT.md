# Nikita OS 5.0.0 — проверка

Проверено локально, не на production. Архив не означает публикацию сайта.

- Автоматические API / validation / planner тесты: 13.
- UI-регрессия в Chromium: 17 групп, без page errors.
- Восемь разделов при ширине 1440 и 390 px, нет горизонтального скролла страницы.
- Все 17 пятничных событий видны, средняя высота строки desktop до 60 px.
- Отдельная колонка времени desktop 136 px, mobile 90 px, без скрытия начала.
- Все 10 исходных учебных заданий видимы на главной и в разделе домашнего.
- Добавление, редактирование, завершение, отмена, сохранение после перезагрузки.
- Полная ширина расписания; мобильный переход к домашнему; поиск и вкладки.
- События и приоритет, повторы курса, избранные ссылки, фокус и самочувствие.
- Текущее/следующее событие по Нью-Йорку; явный выбранный день.
- Пересечения времени, раскрытые спортивные формы, меню, резервная копия.
- Проверка версии и отсутствие соединения; service worker не кэширует API.
- Подготовлены HTML-снимки для визуальной проверки desktop/mobile.

Не проверены: реальный production после пользовательской загрузки, авторизация
в сторонних университетских системах, автоматическая синхронизация (её нет).
Даты старых заданий сохранены, актуальность должен подтвердить пользователь.
Цвета кодируют категории и приоритет, а не гарантируют рост продуктивности.
