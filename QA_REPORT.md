# Проверка Nikita OS 4.0.0

## Результат
- `npm run build`: комплект, совместимость схемы и номер версии проверены.
- `npm test`: 13 тестов, 13 успешно.
- Локальный Chromium, 1440 px и 390 px: 16 сценарных групп, ошибок JavaScript нет.
- Все 8 разделов проверены на обоих размерах без горизонтального скролла страницы.
- Сняты и по отдельности просмотрены экраны: главная (весь день), календарь,
  задачи, ссылки, следующий семестр, фокус, хоккей, настройки — desktop/mobile;
  вход и редактор события — desktop/mobile; загрузка, быстрые ссылки, раскрытые
  старые сроки, спортивные заметки и самоотметки, предупреждение о пересечении,
  диагностика публикации, меню разделов и ошибка соединения — mobile.
- Обнаруженное наложение кнопки быстрого доступа на боковое меню исправлено;
  финальный мобильный снимок просмотрен повторно. Кнопка отмены задачи кликабельна.

## Проверенные сценарии
- Показ всех 12 записей понедельника и всех 17 записей пятницы без прежнего slice.
- Перенос исходной игры на вторник; вручную изменённая дата не перезаписывается.
- Добавление важного события на выбранный день и сохранение после перезагрузки.
- Учебное задание по сроку и предмету, отдельное личное дело; завершение,
  отмена в уведомлении и возврат из выполненных; правка срока и поиск.
- Старые сроки свёрнуты без удаления; избранные ссылки меняются и сохраняются.
- Добавление курса и создание явных календарных повторов.
- Сохранение личного фокуса; сохранение спортивной заметки и её даты.
- Необязательные самоотметки без заранее выбранного балла.
- «Сейчас / дальше» использует настоящее время America/New_York (с фиксированным
  временем только в тестовой среде), не подменяет его выбранным днём календаря.
- Пересечения по времени исключают свободное время, режим и соприкасающиеся
  границы событий; неизвестное время не выдумывается.
- Выгрузка JSON, повторная загрузка сохранённых данных, вход/выход.
- Совпадение версии интерфейса с публичным version.json; страница диагностики.
- Service worker и PWA manifest, версии статических файлов в URL.

## Контраст

текст учебного события 11.92:1; текст тренировки 12.03:1;
граница поля/его фон 4.40:1.

## Границы проверки
Тесты выполнены на локальном сервере с изолированным хранилищем.
Реальный Supabase пользователя и аккаунты GitHub/Vercel не изменялись;
новая сборка не публиковалась автоматически.
На момент проверки публичный основной адрес отдавал прежний зелёный интерфейс;
причину в настройках приватного проекта Vercel без доступа подтвердить нельзя.
Диагностика не требует публиковать ключи или личные данные.

Архив не содержит тестовый сервер, тестовый PIN, .env.local, node_modules,
скриншоты с личными данными или секреты. .env.example содержит только шаблоны.
