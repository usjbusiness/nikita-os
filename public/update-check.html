Если всё ещё старый дизайн

  1. Vercel → проект nikita-os → Deployments. Открой самый новый деплой.
  2. В Source должен быть тот же коммит, которым загружена версия 4.0.0 в GitHub. Статус — Ready, окружение — Production.
  3. Settings → Build and Deployment: Framework — Other; Root Directory — пусто, если package.json и vercel.json лежат в корне GitHub; Output Directory — public.
  4. Если последний коммит здесь не появился: Settings → Git → проверь подключённый репозиторий и production-ветку main. Простая повторная сборка старого коммита не добавит новый код.
  5. Открой основной адрес проекта и эту страницу снова. Никаких SQL-команд или замены ключей для обновления дизайна не нужно.

Эта страница не читает личные данные и ключи. Она проверяет только общедоступный номер сборки.
